# Wenlan 在线更新与中文 Release Notes

## 目标

将应用名称改为“Wenlan · 公众号排版”，提供安全的在线检查更新入口，并在发布版本时自动生成中文更新说明。

## 范围

- Tauri 应用标题、安装包名称和界面品牌统一为“Wenlan · 公众号排版”。
- 顶部增加“检查更新”按钮。
- 应用查询 `kanne-lu/gzh-design-skill` 的最新 GitHub Release，展示当前版本、最新版本与 Release 正文。
- 有新版时，用户点击“前往下载”在系统浏览器中打开该 Release 页面。
- GitHub Actions 从上一个版本标签到当前标签的提交生成中文 Markdown 更新说明，并写入 GitHub Release。

不包含应用内下载/静默安装更新、自动启动检查、用户账号或第三方 AI API 密钥。

## 架构

新增一个最小 Tauri 命令，向 GitHub Releases API 请求最新正式版本。前端只通过该命令获得更新状态，避免浏览器跨域与外部链接处理差异；打开下载页则使用 Tauri 的官方 opener 插件。

更新入口沿用现有顶部操作区。按钮触发后显示加载、已是最新版、可更新或请求失败四种状态。可更新状态显示中文 Release Notes 与“前往下载”按钮；没有更新时不显示下载操作。

## Release Notes

发布工作流在构建前执行项目内脚本：读取上一个 `v*` 标签之后的提交主题，按 Conventional Commit 前缀归类为“新增”“修复”“优化”“维护”，并输出中文 Markdown。对于没有前缀的提交，放在“维护”分类中。

为保证条目本身为中文，后续功能提交主题使用中文；工作流不调用外部 AI 或需要额外密钥。

## 错误处理与验证

- GitHub API 网络失败、返回非成功状态或缺失版本字段时，前端显示“暂时无法检查更新”，不阻断编辑功能。
- 版本相同或远程版本更低时，显示“已是最新版本”。
- 自动 Release Notes 脚本在没有前一标签时汇总当前提交；没有匹配提交时输出“本次发布包含维护更新”。
- 测试覆盖版本比较、Release Notes 中文分组与更新状态判定；打包验证仍生成 Windows NSIS 安装包。
